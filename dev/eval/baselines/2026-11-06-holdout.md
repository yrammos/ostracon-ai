# Hold-out — 2026-11-06, Claude web search for the type

The figure the README quotes. The hold-out sample (`dev/eval/holdout/`, 55
sources) was drawn from the library and never used to develop rules or prompts.

## Provenance

- Code: the Claude-search branch (#109, merged 2026-11-07); before #117
  (`drop_fields`, the first-edition rule) and #122 (bracket-free container keys).
- Runs: `2026-11-06-claude-search-2` (first 10 sources alphabetically, stopped by
  `--budget 1.50` after 9) and `2026-11-06-claude-search-39` (39 others).
  48 sources scored; Ayrey2006, Black2025, Draper2009, Fischer2009, Frisch1991,
  Gould2000 and Judd1998 were not run with this engine.
- Outputs (not in version control): `dev/eval/out/2026-11-06-claude-search-{2,39}.{json,log}`.
- Cost as the harness measured it from token usage (not a bill): $0.60 for 9
  sources (15 searches), $2.84 for 39 (70 searches).

## Configuration

- `model: claude-sonnet-4-6`, no effort setting.
- `gemini_type_check: true`, `type_search: claude` (Claude Haiku 5.5, at most two
  searches per source).
- `enrich_missing_fields: true` (CrossRef and Google Scholar).
- `library_match: true`, `library_exemplars: true`, against the maintainer's
  ~5,500-entry library with each source's own entry excluded.
- `house_cleanup`, `repair_entries`, `validate_entries`, `render_check`,
  `require_langid`: all on.
- The maintainer's private house-style file.

A user without a library, or without the house-style file, should expect lower
figures: library matching and exemplars supply container fields and house form.
