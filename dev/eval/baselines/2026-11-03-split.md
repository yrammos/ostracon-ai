# Baseline — 2026-11-03, rules split from house style

Supersedes `2026-11-03-langid.md` as the reference run. The extracting model
now reads `prompt-context/extraction-rules.md` (generic rules and project
defaults) instead of `CLAUDE.md`, plus a private house-style file sent after
it with precedence. `CLAUDE.md` is development guidance only.

## Provenance

- Code: branch `split-house-style` at `d54df9e` (before its rebase onto
  `7768f55`; the rebase touched no prompt file).
- Model: `claude-sonnet-4-6`, no effort setting.
- House style: a user's private file (three sections: their preamble and the
  languages it loads; `Langid` on every entry; their use of `\shortcite`,
  `\citejournal` and `\headlesscite`), passed via `house_style_file`.
  Not in the repository.
- Ground truth: `expected.bib` as of #65 (`ddd248c`); #69's strip of private
  bookkeeping fields does not change any score.
- Run: 2026-11-03, 11:09–11:23 EET; 61 of 61 produced an entry, no
  extraction failure.
- Cost, measured: $3.62 over 124 calls. No prompt-cache write: a two-source
  trial minutes earlier had already written it. A cold run adds about $0.40.
- Outputs (not in version control): `dev/eval/out/last-run-2026-11-03-run3-house/`,
  `dev/eval/out/2026-11-03-run3-house.json` and `.log`.

## Result

| | `2026-11-03-langid.md` | **This run** |
|---|---|---|
| Entry type | 49/61 | **49/61** |
| exact | 290 | **302** |
| different | 131 | **117** |
| missing | 93 | 95 |
| spurious | 88 | **75** |
| `langid` exact / missing | 57 / 4 | **61 / 0** |

- **No regression.** The same twelve entry types are wrong. `Langid` is now
  on every entry, and right on every one: a rule placed in the house style
  is followed at least as well as it was in the shared guidelines.
- **Slightly better elsewhere, at the edge of the noise floor.** `exact` +12,
  of which `langid` 4, `title` 4, `date` 2; `spurious` −13, spread thinly
  (`entrysubtype` −3; `subtitle`, `note`, `publisher`, `shorttitle` −2 each).
  The static prompt is about 1,300 tokens shorter (69,952 → 68,629, house
  style included), since the development material is gone. No single field moved by more than four, so treat this as unchanged
  rather than as an improvement.
- **Not measured:** the generic rules without any house style, which is what
  a user without a private file gets.
