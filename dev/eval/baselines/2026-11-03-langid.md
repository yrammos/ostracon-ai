- **The rule works.** `Langid` is right on 57 entries, and none was written
  as `english`, so the rewrite guard never acted. The four without one
  (Baumann2006, Gollin2011a, Meeus1980, ScienceDirect2020) were flagged for
  review, as designed.
- **Nothing else moved beyond noise.** Excluding `langid`, `exact` is 233 in
  both Sonnet 4.6 runs. Entry types are the same 49, with the same twelve
  wrong. `spurious` +9 and `different` +5 are scattered one or two per field
  (`subtitle` +4, `note` +3).
- **Model choice.** With the prompt asking for `Langid`, Sonnet 4.6 leads on
  `exact` and `missing` and ties on type. `claude-sonnet-4-6` stays the
  default.
